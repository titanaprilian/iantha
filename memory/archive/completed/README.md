# Completed Action Archive

Completed action occurrences live in monthly files: `YYYY-MM.md` (for example, `2026-11.md`).

Each line records the completion date, stable action ID, context, original action, estimate, energy, and confirmed outcome:

`- [x] [YYYY-MM-DD] A## · @context — action [Nm, energy] — outcome`

Recurring actions create one dated line per confirmed occurrence. Keep `memory/next-actions.md` limited to active, uncompleted actions; do not retain completion history there. Create a monthly file on the first completion recorded for that month.
